نەخشەی تاکتیکی کوردستان — دانان لەسەر GitHub Pages (بەخۆڕایی)

1) هەژمارێکی بەخۆڕایی لە github.com دروست بکە.
2) «New repository» ← ناوێک بنووسە (بۆ نموونە kmap) ← Public ← Create.
3) «uploading an existing file» ← هەموو فایلەکانی ئەم فۆڵدەرە ڕابکێشە (index.html, sw.js, manifest.webmanifest و وێنەکان) ← Commit changes.
4) Settings ← Pages ← Source: Deploy from a branch ← Branch: main و /(root) ← Save.
5) دوای 1-2 خولەک ناونیشانەکەت دەبێت: https://ناوی-هەژمار.github.io/kmap/

لەسەر مۆبایل:
- ئایفۆن: بە Safari بیکەرەوە ← دوگمەی Share ← Add to Home Screen. پاشان لە ئایکۆنەکەوە بیکەرەوە (نەک لە Safari) و فایلی kurdistan.kmap هەڵبژێرە.
- گالاکسی: بە Chrome بیکەرەوە ← ⋮ ← Add to Home screen / Install app ← لە ئایکۆنەکەوە بیکەرەوە و kurdistan.kmap هەڵبژێرە.

فایلی kurdistan.kmap مەخەرە ناو GitHub — زۆر گەورەیە (159 MB) و پێویست ناکات. تەنها لەسەر مۆبایلەکە هەڵیبژێرە.
